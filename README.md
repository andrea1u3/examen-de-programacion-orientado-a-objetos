# Object-Oriented Programming Exam

This project was developed as part of an Object-Oriented Programming exam. 
The application generates a sequence of numbers between a starting value and an ending value provided by the user, and displays the results in a table.

## Features
- Input for starting and ending numbers
- Automatic generation of number sequences
- Display of results in an HTML table
- Iteration through the generated values

## Technologies
- JavaScript
- HTML
- Basic Object-Oriented Programming concepts

## Purpose
The goal of this project was to practice fundamental Object-Oriented Programming concepts such as object creation, attributes, and structured logic while interacting with a web interface.
